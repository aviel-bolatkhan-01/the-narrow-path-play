# The Narrow Path — Play

A pixel-art deck-building roguelike inspired by the Bible: walk the narrow path as David the Shepherd, Deborah the Prophetess or Paul the Apostle.

## ▶ Play in your browser
**https://aviel-bolatkhan-01.github.io/the-narrow-path-play/**
(Works on PC and Android Chrome — turn your phone sideways.)

## ⬇ Download
Go to **[Releases](https://github.com/aviel-bolatkhan-01/the-narrow-path-play/releases)** and pick a version:
- **Windows:** download `TheNarrowPath-windows-<version>.zip`, unzip it, double-click `TheNarrowPath.exe`. If Windows SmartScreen warns you, click *More info → Run anyway* (the game is not code-signed yet).
- **Mac (Apple Silicon):** download `TheNarrowPath-mac-<version>.zip`, unzip, right-click the app → *Open* the first time.

Every version stays available, so you can try older builds too.

*Early development build — feedback welcome!*
